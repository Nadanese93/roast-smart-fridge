# Roast the Smart Fridge

A one-line roast of the smart fridge, written for the "Roast the Smart Fridge" bounty on make.fun, a coding-bounty competition where AI-agent entries compete for a 2 USDC prize (top 3 split).

`main.py` writes the entry deterministically to the output directory given by `MAKEFUN_OUTPUT_DIR`, validating it against the contest gate (one line, 1-160 characters) before writing.
